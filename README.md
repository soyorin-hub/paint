一个基于 **Qt 6 + C++** 的矢量绘图桌面应用。支持绘制基础图形、自由绘制、文字、编组与图层管理，并具备完整的撤销/重做体系、对齐、层级控制，以及 SVG/PNG 导出。

## 功能特性

### 绘图工具
| 工具 | 说明 |
| --- | --- |
| 选择工具 | 点选 / 框选 / 拖动移动图形，8 向缩放框 + 旋转手柄 |
| 直接选择工具 | 顶点/锚点级编辑，贴合轮廓高亮，自由钢笔路径的锚点调整 |
| 矩形 / 椭圆 / 直线 / 三角形 / 菱形 / 箭头 | 基础形状绘制，矩形与椭圆支持圆角调节手柄与贝塞尔椭圆 |
| 自由绘制 | 手绘路径，可进入锚点编辑 |
| 文字 | 双击图形就地编辑，顶部文字工具栏调节字体/字号/加粗等 |
| 橡皮擦 | 擦除图形 |
| 尺子 | 辅助测量，支持方向切换 |

### 图形样式
- 填充色 / 描边色 / 描边宽度 / 线型（实线、虚线等）实时调节
- 属性面板集中编辑选中图形的样式

### 图层与编组
- 多图层管理：新建 / 删除 / 重命名 / 上下移动 / 切换当前层
- 图层锁定（锁定层不可编辑）
- 逻辑编组 / 解组，支持组重命名，组内多选联动移动

### 编辑与操作
- 完整的撤销 / 重做（基于 `QUndoStack` + 命令模式）
- 复制 / 剪切 / 粘贴 / 原位粘贴 / 重复（Duplicate）
- 方向键微调、置顶 / 置底 / 上移 / 下移
- 对齐：左 / 水平居中 / 右 / 顶部 / 垂直居中 / 底部
- 历史面板展示操作记录

### 文件
- 自有格式 `.vdraw`（JSON 序列化）保存与加载
- 导出 SVG / PNG
- 最近文件列表

## 构建

### 依赖
- Qt 6（`Widgets`、`Svg`、`SvgWidgets` 模块）
- CMake ≥ 3.16
- C++17 编译器（项目在 Qt 6.10.1 + MinGW 64-bit 下开发验证）

### 编译步骤

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

或在 Qt Creator 中直接打开 `CMakeLists.txt` 构建运行。

## 运行

构建产物为可执行文件 `Paint`（Windows 下为 `Paint.exe`）。程序默认画布尺寸 800×600，窗口 1280×800，加载浅色主题样式表（`resources/theme.qss`）。

## 项目结构

```
src/
├── app/          # 主窗口（菜单栏、工具栏、停靠窗口、命令分发）
├── canvas/       # 画布视图与场景（QGraphicsView/Scene 封装）
├── shapes/       # 图形基类与各类具体图形
├── tools/        # 工具基类、工具管理器与各绘图工具
├── style/        # 图形样式（填充/描边）
├── layers/       # 图层模型与图层面板
├── properties/   # 属性面板
├── history/      # 历史（撤销）面板
├── document/     # 文档模型与文件读写
└── commands/     # 撤销命令类（命令模式）
resources/
├── icons/        # SVG 图标
├── theme.qss     # 全局浅色主题
└── resources.qrc # Qt 资源清单
```

## 架构说明

- **Document 与场景解耦**：`Document` 维护图层/组/画布尺寸等文档模型，`applyToScene()` 将内容应用到 `QGraphicsScene`。
- **命令模式撤销**：所有可变操作封装为 `QUndoCommand` 子类，经 `QUndoStack` 统一管理；`push()` 会立即调用 `redo()`。
- **逻辑编组**：使用 `ShapeBase::groupId`（`qint64`）标记编组关系，而非 `QGraphicsItemGroup`。
- **图形多态**：`ShapeBase` 统一处理样式、序列化、手柄与直接选择高亮，各类图形重写几何与绘制逻辑。
