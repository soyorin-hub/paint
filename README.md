# Paint
   2
   3 一个基于 **Qt 6 + C++** 的矢量绘图桌面应用。支持绘制基础图形、自由绘制、文字、编组与图层管理，并具备完整的撤销/         重做体系、对齐、层级控制，以及 SVG/PNG 导出。
   4
   5 ## 功能特性
   6
   7 ### 绘图工具
   8 | 工具 | 说明 |
   9 | --- | --- |
  10 | 选择工具 | 点选 / 框选 / 拖动移动图形，8 向缩放框 + 旋转手柄 |
  11 | 直接选择工具 | 顶点/锚点级编辑，贴合轮廓高亮，自由钢笔路径的锚点调整 |
  12 | 矩形 / 椭圆 / 直线 / 三角形 / 菱形 / 箭头 | 基础形状绘制，矩形与椭圆支持圆角调节手柄与贝塞尔椭圆 |
  13 | 自由绘制 | 手绘路径，可进入锚点编辑 |
  14 | 文字 | 双击图形就地编辑，顶部文字工具栏调节字体/字号/加粗等 |
  15 | 橡皮擦 | 擦除图形 |
  16 | 尺子 | 辅助测量，支持方向切换 |
  17
  18 ### 图形样式
  19 - 填充色 / 描边色 / 描边宽度 / 线型（实线、虚线等）实时调节
  20 - 属性面板集中编辑选中图形的样式
  21
  22 ### 图层与编组
  23 - 多图层管理：新建 / 删除 / 重命名 / 上下移动 / 切换当前层
  24 - 图层锁定（锁定层不可编辑）
  25 - 逻辑编组 / 解组，支持组重命名，组内多选联动移动
  26
  27 ### 编辑与操作
  28 - 完整的撤销 / 重做（基于 `QUndoStack` + 命令模式）
  29 - 复制 / 剪切 / 粘贴 / 原位粘贴 / 重复（Duplicate）
  30 - 方向键微调、置顶 / 置底 / 上移 / 下移
  31 - 对齐：左 / 水平居中 / 右 / 顶部 / 垂直居中 / 底部
  32 - 历史面板展示操作记录
  33
  34 ### 文件
  35 - 自有格式 `.vdraw`（JSON 序列化）保存与加载
  36 - 导出 SVG / PNG
  37 - 最近文件列表
  38
  39 ## 构建
  40
  41 ### 依赖
  42 - Qt 6（`Widgets`、`Svg`、`SvgWidgets` 模块）
  43 - CMake ≥ 3.16
  44 - C++17 编译器（项目在 Qt 6.10.1 + MinGW 64-bit 下开发验证）
  45
  46 ### 编译步骤
  47
  48 ```bash
  49 cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
  50 cmake --build build
  51 ```
  52
  53 或在 Qt Creator 中直接打开 `CMakeLists.txt` 构建运行。
  54
  55 ## 运行
  56
  57 构建产物为可执行文件 `Paint`（Windows 下为 `Paint.exe`）。程序默认画布尺寸 800×600，窗口 1280×800，加载浅色主题
     样式表（`resources/theme.qss`）。
  58
  59 ## 项目结构
  60
  61 ```
  62 src/
  63 ├── app/          # 主窗口（菜单栏、工具栏、停靠窗口、命令分发）

  65 ├── shapes/       # 图形基类与各类具体图形
  66 ├── tools/        # 工具基类、工具管理器与各绘图工具
  67 ├── style/        # 图形样式（填充/描边）
  68 ├── layers/       # 图层模型与图层面板
  67 ├── style/        # 图形样式（填充/描边）
  68 ├── layers/       # 图层模型与图层面板
  69 ├── properties/   # 属性面板
  70 ├── history/      # 历史（撤销）面板
  71 ├── document/     # 文档模型与文件读写
  72 └── commands/     # 撤销命令类（命令模式）
  73 resources/
  74 ├── icons/        # SVG 图标
  75 ├── theme.qss     # 全局浅色主题
  76 └── resources.qrc # Qt 资源清单
  77 ```
  78
  79 ## 架构说明
  80
  81 - **Document 与场景解耦**：`Document` 维护图层/组/画布尺寸等文档模型，`applyToScene()` 将内容应用到 `QGraphicsSc
     ene`。
  82 - **命令模式撤销**：所有可变操作封装为 `QUndoCommand` 子类，经 `QUndoStack` 统一管理；`push()` 会立即调用 `redo(
     )`。
  83 - **逻辑编组**：使用 `ShapeBase::groupId`（`qint64`）标记编组关系，而非 `QGraphicsItemGroup`。
  84 - **图形多态**：`ShapeBase` 统一处理样式、序列化、手柄与直接选择高亮，各类图形重写几何与绘制逻辑。
